# Phase D browser captures

Captured 2026-10-24 using `apps/web/e2e/phase-d.cjs`, Playwright 1.64.1 and local Google Chrome on macOS against the real AlumniBridge services. Desktop width: 1440 CSS pixels. Mobile width: 390 CSS pixels. A single tall viewport captures each complete page after layout settles; these are not simulated phone operating systems.

All profile content and accounts are synthetic. The initials image is generated by the harness with browser canvas, not a real photograph or AI-generated asset. No production personal data, stock imagery or third-party visual asset is included. Disposable accounts and uploaded objects are cleaned after testing; permanent slug tombstones remain by design. Public captures deliberately omit the unchecked About field.

- `desktop.png`, `mobile.png`: owner profile, private default, history, skills and server completeness.
- `privacy-desktop.png`: explicit public selection and actual field publication controls.
- `public-desktop.png`, `public-mobile.png`: anonymous allowlisted profile with an unverified badge and selected fields.

These captures show the UI during the completed browser run, including recent success feedback. They do not establish Windows, Podman, screen-reader or production compatibility.
