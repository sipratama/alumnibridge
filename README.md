# AlumniBridge

AlumniBridge is an open-source professional network for university students and alumni. The first community is Mathematics Education at UHAMKA, Indonesia. The design allows additional universities and study programs later.

This repository currently contains the product and architecture foundation only. Application code and deployment configuration are planned in [docs/implementation-plan.md](docs/implementation-plan.md).

## Current environment

At project inception, Go, Node.js, npm, Git, and a PostgreSQL client were available locally. Docker, sqlc, and a migration CLI were not on `PATH`. No Git repository had been initialized. These are observations of the initial workstation, not project requirements; setup instructions will be added with the first executable milestone.
